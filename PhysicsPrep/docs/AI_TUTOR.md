# 连续私人教师：当前可运行范围

在「开始诊断」点击「从基础开始」，选择牛顿第二定律或Born概率；教师面板默认展开。
可输入“我不会”“提示一下”“从最基础讲起”、方程或概念解释。
需要确定性判分时输入“答案：3”或点击提交按钮。自然语言过程只用于追问，不充当成绩。
“完整解析”可直接展示解析，并记为借助解析；“懂了”不更新掌握证据。

教师收到当前题面、知识树关联节点及最近六轮对话。默认请求模型逐步指导；在线失败回退题目提示，保存错误类别，可重试。
模型仍可能违反提示或解释错误，默认不向模型发送当前标准答案，语言输出不覆盖程序判分。
当前回答类型为启发式：明确答案前缀、等号方程、求助、其余概念/运算待区分，不声称精准识别思维过程。

基础生成是两个受控物理模型的参数化题，当前仅数值题、设计难度1；不是任意考点LLM生成。
牛顿模型执行精确有理数方程残差，Born模型执行精确归一化和概率范围检查。
量纲和适用条件固定于模板。校验覆盖这些模型，不代表验证任意复杂物理推导。
`machine_validated=true` 与 `human_verified=false` 分开记录；普通导入不接受自报机器校验。
稳定生成ID缓存已生成题；被报告的题保持暂停，重复生成不会自动解除暂停。

提示后正确不增加独立正确/掌握估计，安排次日独立复测。
基础生成题错误或借助提示后，下一题自动换参数（牛顿模型交替速度增量表述），用于补救/迁移检查。
其他考点沿用现有先修推荐，不宣称已经实现全大纲自动补救课程。
“题目有误”将题库暂停；当前提交返回uncertain，不更新掌握度，历史成绩保留。

## 数据与回滚

启动通过现有Base.metadata.create_all追加`tutor_turns`表；不重写学习历史、不修改既有表列。
提示层级保存在当前题快照与作答反馈，重启仍保留。教师对话存于独立追加表。
升级前使用现有备份按钮导出SQLite。回滚代码时可保留追加表与JSON字段，旧代码忽略它们；
若需要完整恢复，停止服务后恢复升级前备份，注意恢复会丢失备份后的新学习记录。

尚未覆盖：任意考点生成、复杂图示/推导验证、完整五模式路线、真实个体遗忘曲线、真实学习效果实验。
验收测试证明流程和证据约束，不证明学习效率已实证提高。

五种路线已有入口：从零开始使用上述两个模型；快速诊断沿用可解释选择器；指定章节按知识树筛选；
专项补弱使用保存的薄弱节点；到期复习选择保存的到期节点。当前只是近期下一步策略，不是完整课程计划。
