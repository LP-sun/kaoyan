# 初始内容与核验范围

`data/seed_questions.json` 是 30 道新编原创诊断示例，分布为力学10、电磁6、热学4、波光4、量子6。不是教材原题，也不是真题，没有伪造教材页码或例题号。五种题型均覆盖：单选4、多选2、数值9、符号14、简答1。原创为本项目新编内容的来源分类，不能解释为已经由人工教师审核。

每题记录适用条件、可靠推导、提示和核验说明。`verified=true` 表示以下规则或数学核验已经执行，`verification.human_review=false` 明确未经过人工专家审阅。简答题具有参考评分要点，但第一版应返回「需要人工确认」，不能通过关键词出现就断言已掌握。

## 可重复核验

在项目虚拟环境下执行：

```powershell
.\.venv\Scripts\python.exe data\generate_seed.py
.\.venv\Scripts\python.exe data\validate_seed_math.py
```

生成器检查题数与科目分布、知识点引用、唯一ID、先修依赖无环、选择题选项范围；并检查数值计算、正弦概率密度的数值积分。数学核验脚本用 SymPy 从牛顿定律、能量、动量、转动方程、高斯定律、状态方程等重新求解14个符号结果；计算9个数值结果，检查6个选择题答案键及关键恒等式。脚本只读取可信的本项目种子数据，`sympify` 不可用于解析学生或导入者的不可信文本。

选择题中的滚动点速度用刚体速度叠加检查，磁场题用叉积的正交性检查；谐振子零点能采用标准量子谐振子能谱规则，其选择答案检查不构成完整的能谱独立推导。简答支持力零功依据力和位移正交。此核验范围不能宣称覆盖全部教材题或真实考研难度校准。

## 知识树与边界

59个稳定节点组成根→普通物理/量子→科目/章节→具体考点的四级或更深知识树。先修图与父子树独立，先修只用于学习补救而非决定考试范围。学习掌握度在定义中为null，用户掌握度必须另存数据库。

初始题目数量只支持流程验证和基础诊断，不代表完整考试覆盖。角动量、中心力场、微扰、变分等节点已建立，目前无题，界面需明确提示覆盖不足。知识结构是课程参考版本，未经大纲核验，不应标成官方2027大纲。根目录现有教材库与冻结真题保持原样，没有导入这些内容；其未核验OCR题不能因本平台数学判分存在而自动升级为已核验诊断题。

后续编辑须同时修改生成器和种子数据或避免重跑生成器覆盖编辑；任何新增题重新记录来源、核验方法及题目版本，避免改变旧答题快照的含义。表达式变量使用显式白名单，正实参数写入positive_symbols（带符号电荷Q除外），数值题要求按指定单位输入纯数；默认容差1e-6。

## 评分兼容与安全审查

`tests/test_seed_grading.py` 实际调用评分器检查 30 道题中全部客观题的标准答案、滚动的等价表达式及错误反例、正实参数的平方根约束；另检查简答题保持 uncertain，恶意导入/属性访问/列表推导/lambda、超限幂指数、除零、语法错误与超长输入被拒绝。此套测试不使用真实学习数据库，不制造已掌握记录。

评分器通过 AST 白名单构造数学表达式，拒绝任意属性及代码调用。**早期版本使用独立子进程做硬超时；该方案依赖命名管道，在受限环境下会导致全部判分不可用，现已改为纯进程内实现**，通过输入上限（300 字符 / 100 节点 / 嵌套 15 层 / 幂指数 |n|≤20 / 字面量 ≤1e12）与每步墙钟截止时间检查（默认 5 秒，超时返回 uncertain）控制风险。

这是明确的取舍：**进程内实现不再提供操作系统级资源隔离**，因此不能宣称对任意复杂输入都有硬内存或硬 CPU 限额。缓解措施是解析前收紧输入规模，以及 `together → cancel → simplify` 的渐进式化简顺序；残余风险（某个表达式在截止时间内无法被中断）如实记录在 `docs/TEST_REPORT.md` 第 3 节。

单个字母单位（`m`、`s`、`N`…）有歧义，只有题目声明 `expected_unit` 时才按单位处理；`m/s` 这类复合单位可整体识别。单位检查不等同于完整量纲推导，当前种子均要求按题干单位输入纯数。正实数条件已编码，但角度区间、非零电荷以及所有一般物理定义域尚未自动推理；需保留题干约束，无法可靠判断时返回 uncertain。

本项目新编种子先完成明确推导及上述规则/数学验证才设verified=true；运行时新生成的AI题必须先verified=false，不能复制种子审核标记。评分是否可靠、题目答案核验状态、是否人工审核是三个不同维度。
