# 连续刷题：使用与维护

启动：`PhysicsPrep\.venv\Scripts\python.exe PhysicsPrep\app.py`，打开 `http://127.0.0.1:7860`。
默认显示「连续刷题」。选择651普通物理、803量子力学或自动安排，点击「开始刷题」。
之后只需作答、提示、下一题；章节选择可省略。关闭服务后点击「继续刷题」。

## 当前实际行为

`PracticeSessionController` 复用既有题库、选择器、判分器、SQLite和教师接口。
Gradio回调只转发事件，当前题答案和待出题快照留在服务端。

| 阶段 | 行为 |
| --- | --- |
| READY / QUESTION | 自动选题，保存版本、题面、作答起点 |
| HINT / ANSWERING | L1方向、L2关系、L3步骤；只有明确请求才进入L4 |
| FEEDBACK | 保存判分、提示、用时与证据类别，预备下一题；不切换当前题面 |
| REMEDIATION | 一次选择一个前置目标，优先用已有低难度题 |
| VERIFICATION | 使用不同题面/参数，要求无提示正确 |
| NEXT | 学生点击后激活已准备的题目 |
| SUMMARY / SAVED | 汇总独立表现、待复测目标、补救情况并保存 |

作答提交仍由既有token唯一约束与BEGIN IMMEDIATE保证幂等。
控制器状态带版本检查，进程内同数据库共享锁；跨实例旧状态写入被拒绝，界面提示恢复。
提交已完成但控制器尚未保存时，以Attempt记录恢复，不重复更新掌握度。
新题已激活但状态检查点尚未保存时，读取已保存的当前快照恢复题卡。

## 选题与补救

先复用可信现有题（包括符合门槛的教材题），再生成，不为每题调用模型。
模式具有不同候选目标：自适应考虑覆盖/水平/先修；基础模式先给最低难度；
指定章节限制知识树范围；错题模式优先薄弱节点；复习模式优先到期节点。
排序是可解释启发式，未校准为能力概率或考试出现概率。

刚体类错误先用力矩基础诊断。补救正确后做不同表述的验证题，独立成功后返回原知识目标。
其他题按现有先修关系回溯。最终答案不足以确定具体错因，界面保留“可能/无法确定”。
学生可以修改错误类别；数学计算错误可跳过整段概念补救。
完全没思路时可以点击「先补基础」，记录无法下手而不伪造一次错误判分，并安排原目标复测。
补救最大深度3、最长10分钟，超过后换考点并保留复测事项，避免无限循环。
基础提示在离线情况下同样可用；未覆盖的题目只给一般建模引导，不伪造专属推导。

## 自动生成的可信边界

支持七个受控模型：牛顿第二定律、力矩与力臂、固定主轴转动方程、绳无滑动、绕绳滑轮、Born概率、常数波函数归一化。
模型API只提议白名单模型与变式编号；规范题面和答案由受控模型生成。
独立校验器重算答案/归一化积分，检查参数、题面、条件、单位、提示与解析。
滑轮综合题另用能量路径验证，并检查张力/加速度范围及惯量趋零/趋大的极限。
单位关系通过质量、长度、时间的量纲指数运算检查；不是仅填一条“校验通过”说明。
不接受任意LLM生成的复杂物理结论；复杂图示、多步骤近似及高阶量子题仍未自动验证。

`generation.status` 记录generated、validating、machine_validated、rejected或needs_review。
生成结果的`machine_validated`与`human_verified`分开；机器检查不伪造人工审核。
普通导入会清除自报机器校验标记，只有可执行校验入口可以授予练习资格。
报告问题、取消可信标记、冻结、删除或停用题目后，即使已有快照也停止确定性评分。
已有题的编辑/暂停状态不会被重新生成覆盖。
机器缓存会按当前校验规则重新判断资格。只有从未被人工编辑/报告的程序缓存定义可自动更正并递增版本，历史作答快照不变。

稳定生成ID缓存题目；同会话过滤同模型同参数的重复，即使ID不同也不当作新变式。
请求包含目标科目/考点、启发式掌握证据、设计难度、题型、先修ID及最多三条近期错误/题目ID；不上传全量历史。
每会话最多2次候选请求，每次最多2次提议。连续刷题客户端每模型超时最多10秒，不做同模型重试，
最多保留一个备用模型；失败回退本地模型或其他已有题。没有准确价格数据，不报告虚构费用。
记录请求状态和安全错误类别，不记录密钥或原始异常响应。

教材写作JSON已接入同一导入按钮。需显式科目/难度来源、完整答案和检查、
`review.reviewer_kind=human`及题面/解答证据才能进入可信教材池；仅有verified/checked字符串不够。
这是少数教材内容的准入接口，不是开始刷题的前提，AI草稿不会被自动标成人工核验。

## 判分与学习证据

单选/多选使用选项与集合比较；数值/符号复用受控SymPy解析、等价、容差与单位检查。
文字/推导可以获得结构化模型建议（认可步骤、可能问题、下一步），但状态仍为uncertain，不提高掌握度。

证据类别分开保存：独立尝试、提示后完成、解析后完成、同日重复、独立迁移验证、延迟独立复测。
补救后返回已经见过的原题记为原题回练；即使做对，也不增加新的独立掌握证据。
提示后的正确不增加独立正向掌握证据；近24小时同题或同生成模型的重复正确也不继续叠加正向证据，避免跨午夜漏洞。
当天正确不会延长到7/14天；到期且至少间隔一天的独立结果才可支持更长复习间隔。
普通探索练习不推迟尚未完成的到期复测。统计中的独立正确率排除uncertain。

用时是题目打开到提交的窗口时间，每题最多计20分钟；不能当作专注时间测量。
掌握度仍是启发式。自动化测试使用标准答案作为测试预期值，不能冒充真人学习收益。

## 数据迁移与回滚

迁移4追加practice_states及tutor_turns表；不删除既有表、列、题目或学习记录。
题目快照和反馈追加JSON字段，旧记录缺字段时按旧行为解释。
启动前可使用设置页备份SQLite；不要删除现有数据库来升级。
回滚代码可保留追加表，旧代码忽略这些表与新字段。若恢复升级前备份，备份后的新记录会丢失，
因此先另存当前备份、停止服务，再恢复；不要直接清空数据库。

## 可重复验收命令

```powershell
cd PhysicsPrep
.venv\Scripts\python.exe -m pytest tests -q --junitxml=report.xml
.venv\Scripts\python.exe tools/preflight_check.py
.venv\Scripts\python.exe tools/practice_browser_check.py --questions 20
.venv\Scripts\python.exe tools/practice_browser_check.py --minutes 30 --questions 40
```

浏览器脚本使用新建临时目录、独立SQLite与随机本机端口，只停止它自己创建的子进程。
不清空用户库、不改.env、不按全局端口或进程名批量停止服务。
截图与服务日志留在脚本输出的临时目录。--minutes使用真实墙钟计时，不注入假时间。
