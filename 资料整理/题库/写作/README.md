# 人工写作目录

本目录保存逐题人工核验与解析记录，是「提取」之外的第一份**人工内容**。

## 约定

- 一题一文件：`写作/<教材ID>/<题目ID>.json`，UTF-8。
- 稳定 ID 形如 `BK04-思考题-6-11`，**必须原样保留**，不得重编号或去重。
- 字段与状态定义见根目录 [《题库写作指南》](../../../题库写作指南.md)。
- 原始提取记录（`../教材习题.json`、`../教材习题/<教材ID>/习题.json`）由生成器负责，**不要手改**；本目录只新增。

## 校验

```bash
python 资料整理/题库/校验写作.py          # 校验本目录所有记录
```

校验只读、不改文件。它会核对：稳定 ID 是否存在、字段结构、状态取值、
以及状态与内容的一致性（题面 `verified` 需有 `sources` 与 `method`；解答 `checked` 需有 `final_answer` 与 `checks`）。

## 接入网页

`构建教材题库.py` 按稳定 ID 合并本目录记录，把题面与状态带入
`教材题库数据.js` 与离线网页；解析默认折叠，支持「先做题后看答案」。
合并后必须重新运行 `构建教材题库.py`，再抽查实际网页中的公式、图示、跨页题与来源跳转。

## 状态口径（不要混为一谈）

- 题面：`draft` / `verified` / `needs_review`
- 解答：`not_started` / `draft` / `checked` / `needs_review`

`verified` / `checked` **不等于人工专家审定**，只表示脚本核验范围内的记录完整。
